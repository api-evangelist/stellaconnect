# Stella Connect (Medallia Agent Connect)

> Stella Connect, built by StellaService and acquired by Medallia in 2020, is now Medallia Agent
> Connect — a customer service platform pairing real-time customer feedback with agent coaching,
> quality assurance, and recognition. Its API at api.stellaconnect.net covers feedback/service
> recovery requests, reporting data return, and employee user management, authenticated with API
> keys and HMAC SHA256-signed JWTs.

Generated by API Evangelist (method: generated, 2026-07-21) from apis.yml and the harvested
Agent Connect documentation; the provider publishes no llms.txt of its own.

## APIs

- [Agent Connect Requests API](https://docs.medallia.com/en/agent-connect/api/requests): POST
  /v1/requests (create a standard feedback request), POST /v1/recoveries (create a service recovery
  request). x-api-key header auth.
- [Agent Connect Data Return API](https://docs.medallia.com/en/agent-connect/api/data-return): GET
  /v2/data (Feedbacks v2), /v2/coaching/sessions, /v2/qa, /v2/qa/audits, /v2/qa/calibrations —
  sequence-cursor pagination (`after` + sequence_id), 100 requests/minute per key. x-api-key + JWT.
- [Agent Connect User Management API](https://docs.medallia.com/en/agent-connect/api/user-management):
  GET/POST /v2/employees, GET/PUT /v2/employees/{id}, POST /v2/employees/invite, PUT
  /v2/employees/{id}/activate and /deactivate. x-api-key + JWT.
